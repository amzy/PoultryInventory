# Poultry Inventory App Icon

The finalized Poultry Inventory icon is included in `Runner/Assets.xcassets/AppIcon.appiconset`.

This project archive currently does not contain an Xcode `.xcodeproj`/`.xcworkspace`, so the asset catalog is provided but cannot be wired into an absent Xcode target here. In a standard Flutter iOS Runner target, set **Asset Catalog App Icon Set Name** to `AppIcon`.
